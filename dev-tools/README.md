# dev-tools

Development tools for Manutencao Conectada.

## Structure

dev-tools/
├── docker-compose.yml
├── .env                        (generated by sonar-setup.sh, not committed)
├── sonar/
│   └── sonar-project.properties
├── scripts/
│   ├── sonar-setup.sh          first-time SonarQube setup
│   └── sonar-scan.sh           run analysis
└── README.md

## SonarQube

### First time

bash dev-tools/scripts/sonar-setup.sh

This will:
1. Start the SonarQube container
2. Change the default admin password
3. Create the project
4. Generate a token and save it to dev-tools/.env

### Run the scan

bash dev-tools/scripts/sonar-scan.sh

Works on any branch. No need to push to main.
Dashboard: http://localhost:9000/dashboard?id=manutencao-conectada

### Stop

cd dev-tools && docker compose down

## Notes

- Default SonarQube login is admin/admin before setup
