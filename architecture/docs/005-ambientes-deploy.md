# 5. Ambientes e Deploy

## Local (desenvolvimento)
- App pelo Expo Dev Server.
- Backend em processo Node.js local.
- Banco em branch de desenvolvimento do Neon.
- Relatórios no Vercel Blob.

## Produção
- Backend e build web na Vercel.
- Banco gerenciado no Neon.
- Relatórios no Vercel Blob.
- Provedor de LLM (Groq) e fila de jobs (Upstash QStash) externos.
